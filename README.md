# Expense Tracker

## Description
A simple command-line Expense Tracker built using Python. It allows users to add, view, search, analyze monthly spending, and delete expenses. Data is stored in a CSV file.

## Requirements
- Python 3.x

## How to Run

1. Open a terminal in the project folder.
2. Run:

```bash
python expense_tracker.py
```

## Menu Options

1. Add Expense
2. View Expenses
3. Search by Category
4. View Monthly Spending
5. Delete Expense
6. Exit

## Example CSV (expenses.csv)

```
Item,Amount,Category,Date
Coffee,150,Food,2026-08-04
Bus Fare,50,Travel,2026-08-04
Movie,300,Entertainment,2026-08-03
```
